## English

# Icon Bundler

Icon Bundler is a desktop app that converts PNG and JPEG images into icon files for Windows and macOS.

### Features

- Create multi-size `ICO` and `ICNS` files from `PNG`, `JPG`, or `JPEG` images.
- Keep the image's aspect ratio and center it on a transparent square canvas.
- Choose English, Japanese, or Korean in the app.
- Save the output beside the source image. The app asks before replacing an existing file.

### Download

Download the latest version from [GitHub Releases](https://github.com/jyc8369/Icon_Bundler/releases). The release workflow publishes packages for Windows, macOS, and Linux.

### Use

1. Open Icon Bundler and select a `.png`, `.jpg`, or `.jpeg` image.
2. Choose **Convert to ICO** or **Convert to ICNS**.
3. Confirm replacement if the same output file already exists. The output uses the source image's name and is saved in the same folder.

## 한국어

# Icon Bundler

Icon Bundler는 PNG와 JPEG 이미지를 Windows 및 macOS용 아이콘 파일로 변환하는 데스크톱 앱입니다.

### 기능

- `PNG`, `JPG`, `JPEG` 이미지로 여러 크기를 포함한 `ICO` 및 `ICNS` 파일을 만듭니다.
- 이미지 비율을 유지하고 투명한 정사각형 캔버스의 가운데에 배치합니다.
- 앱에서 영어, 일본어, 한국어를 선택할 수 있습니다.
- 결과 파일은 원본 이미지와 같은 폴더에 저장합니다. 같은 파일이 있으면 덮어쓰기 전에 확인합니다.

### 다운로드

[GitHub Releases](https://github.com/jyc8369/Icon_Bundler/releases)에서 최신 버전을 다운로드할 수 있습니다. 릴리스 워크플로는 Windows, macOS, Linux용 패키지를 게시합니다.

### 사용 방법

1. Icon Bundler를 열고 `.png`, `.jpg`, `.jpeg` 이미지를 선택합니다.
2. **Convert to ICO** 또는 **Convert to ICNS**를 선택합니다.
3. 같은 이름의 결과 파일이 이미 있으면 덮어쓸지 확인합니다. 결과 파일은 원본과 같은 이름으로 같은 폴더에 저장됩니다.

## 日本語

# Icon Bundler

Icon Bundler は、PNG や JPEG 画像を Windows と macOS 用のアイコンファイルに変換するデスクトップアプリです。

### 機能

- `PNG`、`JPG`、`JPEG` 画像から複数サイズを含む `ICO` と `ICNS` ファイルを作成します。
- 画像の縦横比を保ち、透明な正方形キャンバスの中央に配置します。
- アプリ内で英語、日本語、韓国語を選択できます。
- 出力ファイルは元画像と同じフォルダーに保存します。同名のファイルがある場合は上書き前に確認します。

### ダウンロード

[GitHub Releases](https://github.com/jyc8369/Icon_Bundler/releases) から最新バージョンをダウンロードできます。リリースワークフローでは Windows、macOS、Linux 向けパッケージを公開します。

### 使い方

1. Icon Bundler を開き、`.png`、`.jpg`、`.jpeg` 画像を選択します。
2. **Convert to ICO** または **Convert to ICNS** を選択します。
3. 同名の出力ファイルがすでにある場合は、上書きするか確認します。出力ファイルは元画像と同じ名前で同じフォルダーに保存されます。
